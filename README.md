# 📋 周报助手

一个简单易用的命令行周报工具，帮助你在本地记录每天的工作内容，随时查看历史，一键生成周报。

> 🤖 本项目由 **kuikuikui** 与 **Claude（Anthropic AI）** 协同开发完成。

---

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 📝 记录今天的工作 | 输入工作内容，自动带上日期保存到本地文件 |
| 📖 查看历史记录 | 浏览所有记录过的工作内容 |
| 📊 生成本周周报 | 自动筛选最近 7 天记录，以**表格形式**展示 |
| 🔍 按日期查找 | 支持多种日期格式（`2026-06-06`、`6月6日`、`6-6`）模糊查找 |

---

## 🚀 快速开始

### 环境要求

- Python 3.6 或更高版本
- 无需安装任何第三方库（只用 Python 自带的标准库）

### 运行

```bash
# 进入项目目录
cd weekly-report

# 启动周报助手
python main.py
```

